Summarise the following work into a PR title and a PR description body. The
title should fit on one line; the body should be a few short paragraphs
covering what changed and why. When a context section appears above the diff,
ground the description in it — reference the originating issue, user ask, or
other anchor it supplies — rather than describing the diff in isolation.

When the context references a GitHub issue that this branch closes or fixes
(e.g. "fix #190", or an issue URL the work implements), end the body with a
line `Closes #N` — or `Closes owner/repo#N` for an issue in another repository
— one line per such issue. Take issue numbers only from the context; never
invent one. Skip issues that are only mentioned in passing.
