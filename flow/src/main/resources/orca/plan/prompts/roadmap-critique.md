Critique the roadmap below. Another agent split the request that follows into
epics; you have not seen its exploration, so check what the roadmap claims
against the code yourself. Find where it is wrong, incomplete, or bigger than
it needs to be, rather than summarise it. Do not manufacture problems: if a
part holds up, leave it.

Check:

- **Coverage** — every part of the request is delivered by some epic.
- **Essentialism** — every epic is needed for the request; nothing beyond it.
- **Order** — each epic depends only on epics before it, and leaves the
  project working.
- **Size** — no epic so small it should merge with a neighbour, or so large it
  should split.
- **Goals** — each goal states its boundary clearly.
- **Brief** — the paths, types, and conventions it names exist and are right.

Report a ranked list of issues, most important first. For each: what is
wrong, the evidence (file and line), and the change to the roadmap. End with a
one-line verdict on the roadmap's overall direction.

Do NOT edit files or run mutating commands — the critique is your only output.
